Sample Processing Flow

Every 22 microseconds, the timer fires an interrupt. The CPU fetches the audio instruction, decodes it, executes the math using the hardware multiplier, sends the result through the AXI4-Lite bus to the PWM engine, which drives the speaker. All in perfect lockstep.
